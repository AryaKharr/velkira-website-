# Integrasi SunDays — 25 Oktober 2026

Kartu SunDays ditambahkan paling depan dalam portofolio Velkira, dengan visual hero kopi dari proyek asli dan tautan Lihat Website. Layout portofolio menjadi empat kartu dalam dua kolom di desktop dan satu kolom di HP.

Demo disalin dari paket publik yang sudah disiapkan di proyek sibling SunDays ke demos/sunsdays/. HTML disesuaikan untuk tampilan nama SunDays sesuai instruksi terbaru pengguna dan tautan kembali menuju ../../index.html#portofolio. Slug folder sunsdays dipertahankan. Proyek sumber di folder sibling tidak diubah.

Foto AI, menu contoh, dan status cafe fiktif tetap dijelaskan di demo dan kredit aset. CSS serta JavaScript demo identik dengan proyek sumber. Tidak ditambahkan checkout, transaksi, backend, atau layanan pihak ketiga.

Pemeriksaan lokal: aset dan anchor di agency/demo, satu kartu SunDays tanpa duplikasi, urutan kartu pertama, kesamaan source CSS/JS, pemeriksaan sintaks, serta 11 tes proyek sumber. Paket hosting hanya memuat file publik yang diperlukan.

Jika proyek SunDays sumber diperbarui, salinan demos/sunsdays/ perlu disinkronkan dan ZIP hosting dibuat ulang.
